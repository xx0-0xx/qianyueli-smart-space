# xx0-0xx

## 项目

### [阡月里 · 智慧空间管理系统](https://github.com/xx0-0xx/qianyueli-smart-space)

面向无人棋牌室的多端空间管理系统，连接用户预约、商家运营、平台管理与智能设备。

- **业务管理**：多门店、房间预约、订单计价、客户会员与经营报表。
- **多端协同**：用户与商家微信小程序、Vue 管理后台、Windows 桌面端。
- **设备接入**：MQTT 通信、设备状态、权限控制与语音配置。

配套硬件采购、项目合作与商业授权，可通过[项目 Issues](https://github.com/xx0-0xx/qianyueli-smart-space/issues)联系。

## 技术方向

`Go` · `Gin` · `GORM` · `MySQL` · `Redis` · `Vue 3` · `TypeScript` · `微信小程序` · `MQTT`
