# GitHub 发布草案

此文件记录准备发布的内容，不表示仓库已在 GitHub 建立。

## 项目仓库

- 建议名称：`qianyueli-smart-space`
- 简介：面向无人棋牌室的多端空间管理系统，涵盖房间预约、订单计价、客户会员、经营报表与 MQTT 设备接入。Go · Vue 3 · 微信小程序。配套硬件采购与商业授权请联系作者。
- 标签建议：`go`、`gin`、`vue3`、`typescript`、`wechat-miniprogram`、`mqtt`、`iot`、`space-management`
- 默认分支：`main`
- 推荐主页展示顺序：项目简介 → 界面截图 → 核心功能 → 技术栈 → 快速开始 → 项目文档。

## 账号主页

个人主页 README 草案位于 `docs/github-profile/README.md`。GitHub 的特殊主页仓库应命名为 `xx0-0xx`，并把该草案放入仓库根目录的 README.md。主页将展示项目链接；该链接在项目仓库实际创建之前不可用。

创建项目后，将其固定到账号主页的 Pinned 区域。本项目的静态截图可以直接在 GitHub README 展示；完整系统需要后端及数据库，不能直接把整个系统部署到 GitHub Pages。
