# 无需数据库的只读界面演示

这是独立的 Python 标准库 fixture 服务，给真实前端提供虚构数据。**不是 Go 后端，也不是完整业务模拟器。**不连接数据库、设备、支付或微信服务。

要求 Python 3.10+，并先完成两个前端的 `pnpm build`，然后在仓库根目录执行：

```powershell
python demo/serve.py
```

| 入口 | 本地地址 | 演示登录 |
| --- | --- | --- |
| 平台后台 | http://localhost:5173 | 用户名 `demo`，口令 `demo` |
| 商家后台 | http://localhost:5174 | 邀请码 `DEMO101` |
| fixture API | http://localhost:8080 | 仅供本地界面读取 |

三个端口只监听 127.0.0.1。端口被占用时请先停止相应本地开发服务，不要与真实 Go 后端同时启动。Ctrl+C 停止。

页面右下角固定标注“界面演示 · 虚构数据 · 只读 · 非生产后台”。登录是演示用途；商家页的协议勾选只沿用原页面控件，演示不创建外部账号，也不提交任何真实资料。

可查看平台首页、门店列表、商家经营看板、订单和详情、会员等级和客户列表，并尝试客户搜索。其他页面没有全面模拟。保存、删除、退款、充值、设备指令等写入请求统一拒绝；不要把错误提示理解为真实后端故障。

演示登录字符串和邀请码均为公开的虚构值，不能用于真实系统。页面中的店名、地址、客户和订单均不对应真实经营数据。

本演示服务不进入后端生产镜像。真实开发仍使用根目录 README 中的 MySQL、Redis、MQTT 与 Go 服务。
